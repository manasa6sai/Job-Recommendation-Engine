# ALPHA Job Recommendation Platform 🚀

**Hackathon Project – Morgan Stanley Alpharetta: Code to Give 2025**

## 🧠 Overview

This project was developed during the **Morgan Stanley 'Code to Give' Hackathon** to support [ALPFA](https://www.alpfa.org/), a nonprofit that empowers Latino professionals. Our solution is a smart job recommendation platform that connects job seekers with relevant opportunities and helps sponsors identify top talent efficiently.

---

## 🌟 Key Features

- 🤖 **AI-Powered Matching** using Cohere Embedding API
- 📄 **Automatic Resume Parsing** (backend implemented)
- 🧠 **Job Description Analyzer** to auto-generate structured postings
- 🎯 **Personalized Job Recommendations**
- 📊 **Admin & Sponsor Dashboards** for match tracking and analytics
- 📌 **Event Matching Engine** to auto-invite candidates based on profile

---

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS  
- **Backend**: FastAPI, Python  
- **Database**: MySQL (InfinityFree / Aiven)  
- **AI**: Cohere API for vector-based text embedding  
- **Hosting**: GitHub, Render, InfinityFree
